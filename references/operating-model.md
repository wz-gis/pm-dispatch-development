# Operating Model Index

The operating examples were split so agents can load only the material needed for the current action:

- Task, Worker runtime, and Evidence structures: `task-examples.md`
- Worker, milestone, terminal delegation, and Heartbeat prompts: `prompts.md`
- Uncertainty, recovery, and hard Blocker decisions: `autonomy.md`
- Task panel layout: `task-panel.md`
- Terminal Gate and user report: `closure.md`

New instructions should link directly to the target reference instead of loading this index.
